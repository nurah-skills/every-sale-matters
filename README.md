# Every Sale Matters

The registration scoreboard for Skills Academy, Matric College and Bellview.

Live site: https://nurah-skills.github.io/every-sale-matters/

## What's here so far

- `index.html` is the sign-in page.
- `signup.html` is the create account page.
- `home.html` is the home page you land on after signing in.

Real accounts aren't set up yet. The sign-in and create account forms show a short notice and don't save or send anything.

To look around, use **Continue with demo account** on the sign-in page. It signs you in as a sample person, and the home page shows sample figures, not real ones. Sign out from the bottom of the menu.

## Folders

```
assets/css   styles
assets/js    session.js  demo sign-in and sign-out
             auth.js     sign-in and create account pages
             home.js     home page and its sample figures
assets/img   logo
```

## Viewing it

Open `index.html` in a browser, or visit the live site.
