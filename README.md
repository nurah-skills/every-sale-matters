# Every Sale Matters

The registration scoreboard for Skills Academy, Matric College and Bellview.

## What's here so far

- `index.html` is the sign-in page.
- `signup.html` is the create account page.

Both pages are design only for now. The forms show a short notice when you submit them, and nothing is saved or sent anywhere.

## Folders

```
assets/css   styles
assets/js    small scripts (show/hide password, form notice)
assets/img   logo
```

## Viewing it

Open `index.html` in a browser, or visit the live site on GitHub Pages.
